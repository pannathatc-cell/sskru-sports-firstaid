# ระบบบันทึกการปฐมพยาบาลงานกีฬา
### คณะพยาบาลศาสตร์ มหาวิทยาลัยราชภัฏศรีสะเกษ · Sports First-Aid & Nursing Care Record System

🌐 **เปิดใช้งาน:** https://pannathatc-cell.github.io/sskru-sports-firstaid/

หน้าเว็บนี้โฮสต์บน GitHub Pages และส่งข้อมูลไปยัง Google Apps Script (Web App) ซึ่งบันทึกลง **Google Sheets** และเก็บรูปภาพใน **Google Drive** ของคณะ — ข้อมูลผู้รับบริการไม่ได้ถูกเก็บใน repository นี้

**ความสามารถ**
- บันทึกการตรวจรักษา ซักประวัติ สัญญาณชีพ Pain score คัดแยกระดับความเร่งด่วน (เขียว/เหลือง/แดง)
- กลุ่มโรค 6 ระบบ: กล้ามเนื้อและกระดูก · ประสาท · หลอดเลือด · หัวใจ · ทางเดินหายใจ · ทางเดินอาหาร (+ ผิวหนัง/บาดแผล · ความร้อน · อื่น ๆ)
- คลังยา/เวชภัณฑ์ ตัดสต็อกอัตโนมัติ รับเข้า ตรวจนับ เช็คอุปกรณ์
- แดชบอร์ด · รายงานประจำวันพิมพ์ได้ · บันทึกการใช้งาน (Audit log)
- 🎤 พูดแทนพิมพ์ · 📷 ถ่ายภาพ/แนบไฟล์ (เก็บใน Google Drive)

**การตั้งรหัสทีม (PIN)** — ปัจจุบันยังไม่เปิดใช้ หากต้องการ ให้ใส่รหัสใน `var ACCESS_PIN = '';` ในไฟล์ Apps Script แล้ว Deploy เวอร์ชันใหม่ หน้าเว็บจะถามรหัสอัตโนมัติ
